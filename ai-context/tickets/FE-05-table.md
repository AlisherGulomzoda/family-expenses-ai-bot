# FE-05. Таблица трат: сортировка, пагинация, состояния (десктоп)

**Оценка:** 2.5 ч · **Зависит от:** FE-03 · **Ветка:** `feature/FE-05-table`
**Дизайн:** артборды `Main`, `MainLoading`, `MainEmpty`, `MainError`, `EdgeCases`; `design-spec.md` §4 «Таблица и список», «Состояния списка»

## Цель
Список трат по фильтру с серверной сортировкой и пагинацией.

## Объём
- Data Table (TanStack Table, `manualSorting`, `manualPagination`), `table-fixed`, колонки: Дата 140 · Кто 176 · Категория 176 · Сумма 160 · Комментарий (остаток) · действия 104 px; строка 52px; шапка `bg-muted`; `hover:bg-accent`.
- Сортировка «Дата» и «Сумма» — Button `ghost sm` в заголовке, иконки `ArrowDown`/`ArrowUp`/`ArrowUpDown`, `aria-sort`; состояние в URL (FE-03).
- Ячейки: Avatar + имя (`truncate`, `title`); Badge категории (`CATEGORIES[code].badge`, иконка); сумма `text-right tabular-nums whitespace-nowrap`; комментарий `truncate` + Tooltip **только если текст обрезан**, `tabIndex={0}`.
- Действия: `Pencil` (открывает диалог редактирования, FE-06), `Trash2` (подтверждение, FE-07); `aria-label="Удалить: Кофе, 350 ₽"`.
- Pagination: «Показано 1–10 из 37», 10 на страницу (`limit=10`), активная страница `bg-primary`.
- Состояния: Skeleton (настоящие заголовки, 6 строк, `aria-busy`), Empty `Receipt` («За выбранный период трат нет» + «Сбросить фильтры» + «Добавить трату»), Error `CloudOff` (`role="alert"`, «Повторить» → refetch).
- Обёртка `hidden md:block`, на `md` — `overflow-x-auto min-w-[900px]`.

## Критерии приёмки
- [ ] Тест (MSW): смена сортировки и страницы меняет запрос; пустое и ошибочное состояния отображаются.
- [ ] Длинный комментарий, сумма 1 250 000,50 ₽, длинное имя не ломают раскладку (артборд `EdgeCases`).
- [ ] Совпадает с артбордом `Main` в обеих темах.

Что сделано:
- `ExpensesTable` — `table-fixed`, колонки 140/176/176/160/остаток/104 px, строки 52px, шапка `bg-muted`, `hover:bg-accent`; дата `dd.MM.yyyy`, аватар + имя (`truncate`, `title`), бейдж категории, сумма справа `tabular-nums`, комментарий — `TruncatedText`, действия ✎/🗑 приглушены до hover/focus строки, корзина краснеет; `aria-label` «Изменить/Удалить: кофе, 350 ₽».
- Сортировка «Дата»/«Сумма» — серверная, состояние в URL; новая колонка начинает с ↓; `aria-sort` на `th`; при загрузке новой страницы прежние строки остаются полупрозрачными (`keepPreviousData`).
- `TablePagination` — «Показано 1–10 из 37», страницы с многоточием (`paging.ts`: 1 … 5 6 7 … 12), активная `bg-primary`; ссылки — настоящие URL (открываются в новой вкладке), обычный клик меняет страницу без перезагрузки; русские подписи «Назад/Вперёд», «Страница N».
- Состояния: загрузка — реальные заголовки + 6 строк скелетона, `aria-busy`, без пагинации; пусто — Empty `Receipt` «За выбранный период трат нет» + «Сбросить фильтры» (только при нестандартных фильтрах) + «Добавить трату»; ошибка — Empty `CloudOff`, `role="alert"`, «Повторить».
- `TruncatedText` — подсказка только если текст реально обрезан (`scrollWidth > clientWidth`); триггер — `<button type="button">`, фокусируется с клавиатуры.

Отличия от плана / решения:
- **Без TanStack Table** (D44): установилась v9 с новым API; v8 вызвала замечания линтера (`incompatible-library` с React Compiler, 8× «компонент объявлен во время рендера» в `cell`/`header`). Сортировка и пагинация у нас серверные, колонки статичные — библиотека ничего не давала. Колонки — статический массив на уровне модуля, ячейки — маленькие компоненты.
- Триггер подсказки — `button`, а не `span tabIndex=0` (jsx-a11y: `tabIndex` только у интерактивных элементов).
- Действия ✎/🗑 пока без обработчиков — подключаются в FE-06/FE-07; «Добавить трату» — FE-06.
- Таблица пока видна и на узких экранах (горизонтальная прокрутка, `min-w-[900px]`); карточки на телефоне — FE-08.
