# FE-04. Сводка и «По категориям» (десктоп)

**Оценка:** 1.5 ч · **Зависит от:** FE-03 · **Ветка:** `feature/FE-04-summary`
**Дизайн:** артборды `Main`, `MainLoading`, `MainEmpty`, `MainError`; `design-spec.md` §4 «Сводка», §5

## Цель
Итоги по **всему фильтру** (не по странице) из `/api/expenses/summary`.

## Объём
- Карточки: «Итого» (`text-[40px] font-semibold tabular-nums`), «Трат», «Средняя трата» (`total / count`, при 0 — «0 ₽»).
- Строка «Сводка по всем N тратам по фильтру…» (`text-muted-foreground`, `aria-live="polite"`).
- Card «По категориям»: строки с иконкой в круге 28px, названием, Progress `h-2` цвета `bg-chart-N` (длина относительно максимума), суммой и долей; сетка `grid-cols-[148px_1fr_112px_40px]`; сортировка по сумме; категории с нулём не показываются.
- Раскладка по брейкпоинтам: `md` — три карточки в ряд + «По категориям» на всю ширину; `lg+` — `grid-cols-[minmax(380px,5fr)_7fr]`.
- Состояния: Skeleton (карточки + 7 строк категорий), пусто (0 ₽ и пустая диаграмма), ошибка («—» в карточках).

## Критерии приёмки
- [ ] Тест: доли и сортировка категорий считаются корректно, «Средняя трата» не делит на ноль.
- [ ] Совпадает с артбордами `Main`, `MainLoading`, `MainEmpty`, `MainError`, `MainDark`.
