# FE-10. Сверка с дизайном, доступность, финальные тесты

**Оценка:** 1.5 ч · **Зависит от:** FE-01…FE-09 · **Ветка:** `feature/FE-10-polish`
**Дизайн:** все 18 артбордов, `design-spec.md` целиком

## Цель
Финальная проверка перед сдачей: всё совпадает с дизайном и работает с клавиатуры.

## Объём
- Проход по всем 18 артбордам в светлой и тёмной теме на 1440 / 1024 / 768 / 390 px, список расхождений → исправления.
- Доступность: обход Tab по всей странице, видимый фокус, `aria-label` у иконок-кнопок, `aria-sort`, `aria-live` у сводки, `role="alert"` у ошибки; проверка axe (расширение браузера или `vitest-axe` на ключевых компонентах).
- Пограничные значения из `EdgeCases`.
- Производительность: ленивая загрузка `ExpenseFormDialog` (`React.lazy`) и разбиение вендорных чанков — бандл 720 КБ / 223 КБ gzip после FE-06, Vite предупреждает о чанке > 500 КБ.
- Скриншоты главного экрана (светлая/тёмная, десктоп/телефон) в `docs/screenshots/` — для README.

## Критерии приёмки
- [ ] Нет серьёзных замечаний axe.
- [ ] `npm run lint`, `typecheck`, `test`, `build` проходят.
- [ ] Скриншоты сохранены.
