# FE-06. Диалог «Новая трата» / «Редактирование траты»

**Оценка:** 3 ч · **Зависит от:** FE-02 · **Ветка:** `feature/FE-06-expense-form`
**Дизайн:** артборды `ExpenseDialog`, `DialogNew`, `DialogErrors`, `DialogEdit`, `DialogEditDark`, `Toasts`; `design-spec.md` §4 «Диалоги и уведомления»

## Цель
Создание и редактирование траты в одном компоненте.

## Объём
- Dialog `sm:max-w-[520px] rounded-xl`; DialogTitle «Новая трата» / «Редактирование траты».
- DialogDescription: для новой — «Траты из Telegram-бота появляются здесь сами…»; для редактирования — по полю `source`: `bot` → «Записано через Telegram-бота», `web` → «Добавлено в веб-панели» (D22).
- Форма: react-hook-form + zod, поля через Field + Label, ошибки FieldError с `AlertCircle` и `aria-invalid`, необязательное — «— необязательно»:
  - **Член семьи** — Select + Avatar; по умолчанию: член семьи из фильтра → последний выбранный (localStorage) → первый в списке (D21, без «(вы)»);
  - **Сумма, ₽** — InputGroup `h-14 text-[28px]`, `inputMode="decimal"`, «₽» справа, запятая/точка, ≤ 2 знаков, > 0, подсказка «Можно с копейками: 349,90», ошибка «Укажите сумму»;
  - **Категория** — ToggleGroup плиток `grid-cols-4`, выбранная: фон `chart-N-soft`, рамка 2px `chart-N-ink` + `Check`; ошибка «Выберите категорию»;
  - **Дата** — Popover + Calendar `single`, по умолчанию «Сегодня, 16.10.2026», «Вчера, …»;
  - **Комментарий** — Textarea `rows={2}`, `maxLength={500}`, placeholder «Например: кофе с коллегами».
- Кнопки: «Отмена» `secondary`; «Сохранить» `min-w-[136px]` → при отправке `disabled` + Spinner + «Сохраняем…» (`disabled:opacity-100`); в режиме редактирования слева «Удалить» `ghost text-destructive` (открывает FE-07).
- Ошибки 422 с бэкенда раскладываются по полям (`fields`), прочие — toast с «Повторить».
- Тосты: «Трата добавлена» / «Изменения сохранены» с описанием «Кофе · 350 ₽ · Алишер», 4 с; ошибка — `duration: Infinity`, `closeButton`.
- Мобильная полноэкранная версия — в FE-08.

## Критерии приёмки
- [ ] Тесты (RTL + MSW): валидация пустой формы, сумма «349,90» → `amount: 349.9`, 422 от сервера показывается под полем, успешное создание закрывает диалог и обновляет список/сводку.
- [ ] Клавиатура: фокус в диалоге зациклен, Esc закрывает, плитки категорий выбираются стрелками.
- [ ] Совпадает с артбордами `DialogNew`, `DialogErrors`, `DialogEdit`, `DialogEditDark`.

## Итог реализации (2026-10-16) — ✅ готово, ⏳ визуальная сверка пользователем

Проверено: `format:check` ✓, `typecheck` ✓, `lint` — 0, `test` — **105/105** (диалог 11: валидация до отправки, создание с проверкой тела POST и тоста, член семьи по умолчанию из фильтра и «последний выбранный», 422 под полем с фокусом, ошибка сохранения + «Повторить», «Сохраняем…», редактирование через PUT; правила формы 4), `build` ✓.

Что сделано:
- `expenseForm.ts` — zod-схема (тексты и лимиты как на бэкенде: сумма > 0 и ≤ 100 000 000 ₽, ≤ 2 знаков, дата не позже завтра, комментарий ≤ 500), `newValues`/`editValues`, `toBody` (копейки → рубли без float, пустой комментарий → `null`), `API_FIELDS` (422 → поля формы), `defaultMember` (фильтр → последний выбранный из localStorage → первый) и `rememberMember` (localStorage в try/catch).
- `ExpenseFormDialog` — один компонент для «Новая трата» / «Редактирование траты» (`key` по трате — состояние не протекает между открытиями); описание по `source` («Записано через Telegram-бота» / «Добавлено в веб-панели»); поля Field+Label, ошибки с `AlertCircle` и `aria-invalid`, «— необязательно» без звёздочек; сумма — InputGroup `h-14 text-[28px]`, `inputMode="decimal"`, «₽», подсказка «Можно с копейками: 349,90»; категория — 7 плиток ToggleGroup (выбранная: фон `chart-N-soft`, кольцо 2px `chart-N-ink`, галочка; стрелки клавиатуры — из Radix); дата — Popover + Calendar, «Сегодня/Вчера, …», дни после завтра недоступны; «Сохранить» → Spinner + «Сохраняем…» (`disabled:opacity-100`); «Удалить» в редактировании — если передан `onDelete` (FE-07).
- Успех: тост «Трата добавлена» / «Изменения сохранены» с «Аптека · 349,90 ₽ · Мадина», 4 с; списки и сводка обновляются (инвалидация).
- `components/ui/dialog.tsx`: sr-only «Close» → «Закрыть».
- `src/test/renderApp.tsx` — общий рендер приложения для тестов; в setup — `toast.dismiss()` между тестами (у sonner глобальное хранилище — тост из одного теста «протекал» в другой).

Найдено тестами и исправлено:
- **Ошибка сохранения в тосте была недоступна**: модальный Radix-диалог отключает `pointer-events` у всего вне себя (тосты тоже), а клик вне диалога закрыл бы его и потерял введённое. Ошибка и «Повторить» теперь **внутри диалога** (`role="alert"`), форма сохраняется.
- `new Date()` в рендере поля даты (правило purity / React Compiler) → `useState(() => addDays(new Date(), 1))`.

Отличия от плана:
- Ошибка сохранения — inline-блок в диалоге, а не тост (см. выше); для удаления (FE-07) тост остаётся — там диалог уже закрыт.
- Полноэкранная форма на телефоне — FE-08.
- Бандл вырос до 720 КБ (223 КБ gzip: zod, react-hook-form) → в FE-10 ленивая загрузка диалога (`React.lazy`) и разбиение на чанки.
