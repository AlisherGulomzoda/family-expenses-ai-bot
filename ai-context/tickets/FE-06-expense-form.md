# FE-06. Диалог «Новая трата» / «Редактирование траты»

**Оценка:** 3 ч · **Зависит от:** FE-02 · **Ветка:** `feature/FE-06-expense-form`
**Дизайн:** артборды `ExpenseDialog`, `DialogNew`, `DialogErrors`, `DialogEdit`, `DialogEditDark`, `Toasts`; `design-spec.md` §4 «Диалоги и уведомления»

## Цель
Создание и редактирование траты в одном компоненте.

## Объём
- Dialog `sm:max-w-[520px] rounded-xl`; DialogTitle «Новая трата» / «Редактирование траты».
- DialogDescription: для новой — «Траты из Telegram-бота появляются здесь сами…»; для редактирования — по полю `source`: `bot` → «Записано через Telegram-бота», `web` → «Добавлено в веб-панели» (D22).
- Форма: react-hook-form + zod, поля через Field + Label, ошибки FieldError с `AlertCircle` и `aria-invalid`, необязательное — «— необязательно»:
  - **Член семьи** — Select + Avatar; по умолчанию: член семьи из фильтра → последний выбранный (localStorage) → первый в списке (D21, без «(вы)»);
  - **Сумма, ₽** — InputGroup `h-14 text-[28px]`, `inputMode="decimal"`, «₽» справа, запятая/точка, ≤ 2 знаков, > 0, подсказка «Можно с копейками: 349,90», ошибка «Укажите сумму»;
  - **Категория** — ToggleGroup плиток `grid-cols-4`, выбранная: фон `chart-N-soft`, рамка 2px `chart-N-ink` + `Check`; ошибка «Выберите категорию»;
  - **Дата** — Popover + Calendar `single`, по умолчанию «Сегодня, 16.10.2026», «Вчера, …»;
  - **Комментарий** — Textarea `rows={2}`, `maxLength={500}`, placeholder «Например: кофе с коллегами».
- Кнопки: «Отмена» `secondary`; «Сохранить» `min-w-[136px]` → при отправке `disabled` + Spinner + «Сохраняем…» (`disabled:opacity-100`); в режиме редактирования слева «Удалить» `ghost text-destructive` (открывает FE-07).
- Ошибки 422 с бэкенда раскладываются по полям (`fields`), прочие — toast с «Повторить».
- Тосты: «Трата добавлена» / «Изменения сохранены» с описанием «Кофе · 350 ₽ · Алишер», 4 с; ошибка — `duration: Infinity`, `closeButton`.
- Мобильная полноэкранная версия — в FE-08.

## Критерии приёмки
- [ ] Тесты (RTL + MSW): валидация пустой формы, сумма «349,90» → `amount: 349.9`, 422 от сервера показывается под полем, успешное создание закрывает диалог и обновляет список/сводку.
- [ ] Клавиатура: фокус в диалоге зациклен, Esc закрывает, плитки категорий выбираются стрелками.
- [ ] Совпадает с артбордами `DialogNew`, `DialogErrors`, `DialogEdit`, `DialogEditDark`.
