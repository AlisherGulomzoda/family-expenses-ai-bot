# FE-08. Мобильная версия (< 768px)

**Оценка:** 3 ч · **Зависит от:** FE-04, FE-05, FE-06, FE-07 · **Ветка:** `feature/FE-08-mobile`
**Дизайн:** артборды `MobileMain`, `MobileMainFull`, `MobileFilters`, `MobileCreate`, `EdgeCases`; `design-spec.md` §4, §5

## Цель
Панелью удобно пользоваться с телефона.

## Объём
- Шапка: `text-xl` + тема (`ghost icon size-11`), шапка и строка фильтров `sticky top-0`.
- Плавающая кнопка «+» (`fixed bottom-6 right-4 size-14 rounded-full shadow-lg`), у списка `pb-28`.
- Фильтры: кнопка «Фильтры (N)» (счётчик нестандартных фильтров) + чипы периодов (ToggleGroup `outline`, `overflow-x-auto`, `h-11 rounded-full`) → **Drawer** с ToggleGroup члена семьи / периода / категории, «Выбрать даты», «Сбросить» в шапке, «Применить» внизу (фильтры применяются только по кнопке).
- Сводка: одна Card — «Итого» `text-4xl`, «N трат · в среднем …», stacked BarChart (`layout="vertical"`, высота 12px, обводка 2px `var(--card)`) + три главные доли текстом + Collapsible-легенда «По категориям: N» / «Скрыть категории».
- Список: Item-карточки (`md:hidden`) — иконка категории в круге 40px, комментарий + «Мадина · 30 сен», сумма `shrink-0`, DropdownMenu «⋯» («Изменить», «Удалить» `destructive`, пункты `h-11`).
- «Показать ещё N» (`outline lg w-full`) вместо пагинации — `useExpensesInfinite`, по 10.
- Форма траты во весь экран: `max-md:h-dvh max-md:max-w-none max-md:rounded-none`, сумма первым полем с `autoFocus`, кнопки закреплены внизу.
- Тосты `top-center` на телефоне.
- Все интерактивные элементы ≥ 44px, ввод 16px (без зума в iOS).

## Критерии приёмки
- [ ] На ширине 390px совпадает с артбордами `MobileMain`, `MobileMainFull`, `MobileFilters`, `MobileCreate`; нет горизонтальной прокрутки страницы.
- [ ] Тест: счётчик «Фильтры (N)», «Показать ещё» догружает следующую порцию.
- [ ] Переход через 768px не теряет состояние фильтров.

## Коммит
`feat(frontend): add mobile layout with filter drawer, cards and load more`

## Итог реализации (2026-10-16) — ✅ готово, ⏳ визуальная сверка пользователем (DevTools → режим телефона)

Проверено: `format:check` ✓, `typecheck` ✓, `lint` — 0, `test` — **121/121** (мобильные 9 на ширине 390px: раскладка без таблицы и с одним «+»; «Показать ещё»; меню карточки → полноэкранная форма с фокусом на сумме; удаление из меню; шторка: черновик применяется только по «Применить», «Сбросить» + закрытие без применения ничего не меняют, счётчик «Фильтры, выбрано: N»; чипы периода; сводка с легендой; переход через 768px сохраняет фильтры), `build` ✓.

Что сделано:
- **Переключение по JS** (`shared/useMediaQuery.ts`, `useIsDesktop` = `(min-width: 768px)`): рендерится только одна версия → телефон не грузит страницы таблицы, десктоп — бесконечный список; в DOM нет дублей фильтров/кнопок. Состояние в URL → переход через 768px ничего не теряет.
- Тесты: управляемый `matchMedia` (`src/test/viewport.ts`, по умолчанию 1280px; `setViewport(PHONE)`).
- `MobileFilters` — «Фильтры» + Badge-счётчик (`countFilters` в `urlState.ts`: член семьи, период ≠ «этот месяц», категория), чипы периодов с горизонтальной прокруткой (`h-11 rounded-full`, выбранный `bg-foreground text-background`); Drawer (vaul): ToggleGroup член семьи (аватары) / период (чипы + «Выбрать даты» → встроенный календарь) / категория (точки), «Сбросить» в шапке, «Применить» внизу; черновик сбрасывается на каждое открытие.
- `PeriodCalendar` + `useRangeClicks` — логика «два клика = период» вынесена и используется и в Popover десктопа, и в шторке.
- `MobileSummary` — одна карточка: «Итого» `text-4xl`, «N трат · в среднем …», полоса долей категорий (div’ы, 2px зазоры), три главные доли текстом, Collapsible «По категориям: N» / «Скрыть категории» (шеврон поворачивается).
- `ExpenseCards` — Item-карточки (иконка 40px, комментарий, «Мадина · 30 сен», сумма, меню «⋯» с «Изменить»/«Удалить» `h-11`), `useExpensesInfinite`, «Показать ещё N» (по 10), `pb-28` под «+», скелетон/пусто/ошибка — общие с таблицей (`ListStates.tsx`).
- Шапка на телефоне: `text-xl`, тема `ghost size-11`, шапка и строка фильтров `sticky top-0` с размытым фоном; плавающая «+» `fixed bottom-6 right-4 size-14 rounded-full shadow-lg`.
- Форма на телефоне: во весь экран (`h-dvh`, без скруглений), сумма первым полем (`order-first`) и получает фокус при открытии, кнопки прилипают к низу.
- Тосты: `bottom-right` на десктопе, `top-center` на телефоне (не перекрывают «+»).
- Все кнопки/чипы/пункты меню на телефоне ≥ 44px.

Отличия от плана / решения:
- **Полоса долей — на div’ах, без Recharts** (D46): одна полоса не стоит ~100 КБ библиотеки графиков; `components/ui/chart.tsx` и `recharts` удалены как неиспользуемые.
- Мобильная/десктопная версии — JS (`useIsDesktop`), а не `hidden md:block` (D47) — см. выше.
- Бандл: 789 КБ / 241 КБ gzip — ленивая загрузка диалогов/шторки и чанки в FE-10.
