# FE-03. Каркас страницы, шапка, состояние в URL, фильтры (десктоп)

**Оценка:** 3 ч · **Зависит от:** FE-02 · **Ветка:** `feature/FE-03-layout-filters`
**Дизайн:** артборды `Main`, `CategorySelect`; `design-spec.md` §4 «Шапка и фильтры», §5

## Цель
Страница с шапкой и рабочими фильтрами, состояние которых живёт в URL.

## Объём
- `useUrlState` — фильтры, сортировка, страница ↔ query (`user_id`, `from`, `to`, `period`, `category`, `sort`, `order`, `page`); значения по умолчанию: «Этот месяц», сортировка `spent_at desc`, страница 1; при смене фильтра страница сбрасывается на 1; невалидные значения из URL игнорируются.
- Layout: контейнер `max-w-[1280px] mx-auto`, поля `px-4 md:px-6 lg:px-8`.
- Шапка: заголовок «Семейные расходы», переключатель темы (Button `outline icon`, `Moon`/`Sun`, `aria-label`), кнопка «Добавить трату» (открывает диалог из FE-06).
- Фильтры (≥ `md`):
  - Select «Член семьи» с Avatar («Все члены семьи» + имена из `/api/users`);
  - Popover + Calendar `mode="range"`, `numberOfMonths={2}`, `locale={ru}`, подпись «1–31 окт 2026»;
  - ToggleGroup быстрых периодов (Сегодня · Неделя · Этот месяц · Прошлый месяц), ручной выбор дат снимает выделение;
  - Select «Категория» с цветной точкой;
  - «Сбросить» (`ghost`, `RotateCcw`) — только если фильтры отличаются от стандартных.
- Перенос строки фильтров по брейкпоинтам — как в `design-spec.md` §5.

## Критерии приёмки
- [ ] Тест `useUrlState`: чтение/запись, дефолты, сброс страницы, мусор в URL.
- [ ] Перезагрузка страницы сохраняет фильтры; ссылка с фильтрами открывается в том же состоянии.
- [ ] Визуально совпадает с артбордом `Main` (верхняя часть) в светлой и тёмной теме.
