## Порядок реализации (предложение)

Сначала то, что оценивают сильнее всего (бот и агент), затем панель, затем документация:

1. **Ядро бэкенда:** BE-01 → BE-02 → BE-03 → BE-04 → BE-05 → BE-06
2. **Бот и агент:** BE-07 → BE-08 → BE-09 → BE-10 → BE-12
3. **Веб-панель:** FE-01 → FE-02 → FE-03 → FE-04 → FE-05 → FE-06 → FE-07 → FE-08 → FE-09
4. **Качество:** BE-11 (eval + доработка промпта) → FE-10
5. **Сдача:** CM-01 → (BE-13, если есть время)

После BE-03 фронтенд не зависит от бэкенда (MSW-моки), поэтому шаги 2 и 3 при желании можно чередовать.
