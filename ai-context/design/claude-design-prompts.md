## Промт 0 — Контекст и дизайн-система

```
Мы проектируем веб-панель «Семейные расходы». Контекст продукта:
- Члены семьи записывают траты через Telegram-бота с ИИ («кофе 350», «такси 1200 вчера»).
- Веб-панель нужна главе семьи: видеть траты всех членов семьи, фильтровать, добавлять, редактировать и удалять.
- Пользователь — обычный человек, не бухгалтер. Заходит пару раз в неделю, часто с телефона. Главное — быстро понять «сколько и на что потратили» и легко поправить запись.
- Язык интерфейса — русский. Валюта — рубли, формат «24 350 ₽», даты «15.10.2026» / «15 окт».

Технические ограничения (важно, дизайн будет реализован 1:1):
- Стек: React + Tailwind CSS + shadcn/ui (Radix). Используй только паттерны и компоненты, которые есть в shadcn/ui: Button, Card, Table (Data Table), Dialog, AlertDialog, Select, Popover + Calendar (range), Input, Textarea, Badge, Skeleton, Toast (sonner), Chart (Recharts), Pagination, DropdownMenu.
- Цвета и радиусы — через токены shadcn (background, foreground, card, muted, primary, destructive, border, ring, chart-1…chart-7), сетка отступов Tailwind (4px).
- Нужны светлая и тёмная темы.

Сначала предложи дизайн-систему:
1. Палитру (светлая + тёмная) в виде токенов shadcn. Акцент — спокойный, «финансовый», без кислотных цветов.
2. 7 цветов категорий для бейджей и диаграммы (должны различаться в обеих темах и для людей с нарушением цветовосприятия):
   Еда, Транспорт, Жильё, Развлечения, Здоровье, Покупки, Другое. К каждой — иконка из набора lucide.
3. Типографику (шрифт с хорошей кириллицей и табличными цифрами для сумм), размеры заголовков/текста.
4. Радиусы, тени, отступы.
Покажи это одной страницей-гайдом.
```

## Промт 1 — Главный экран (десктоп, светлая тема)

```
Теперь главный экран панели, ширина 1440px, светлая тема, на основе дизайн-системы.

Структура сверху вниз:
1. Шапка: название «Семейные расходы», справа переключатель темы (иконка солнце/луна) и основная кнопка «+ Добавить трату».
2. Панель фильтров в одну строку:
   - Select «Член семьи» (Все / Алишер / Мадина / Тимур / Зарина);
   - выбор периода (Popover с календарём-диапазоном), рядом быстрые варианты-чипы: Сегодня · Неделя · Этот месяц · Прошлый месяц (активен «Этот месяц»);
   - Select «Категория» (Все + 7 категорий с цветной точкой);
   - ghost-кнопка «Сбросить» (видна, только когда фильтры отличаются от дефолтных).
3. Блок сводки — две колонки:
   - слева карточки: «Итого за период: 48 720 ₽», «Трат: 37», «Средняя трата: 1 317 ₽»;
   - справа карточка «По категориям»: горизонтальная bar-диаграмма или donut с легендой, суммы и проценты (Еда 16 400 ₽ 34%, Жильё 12 000 ₽ 25%, Транспорт 7 300 ₽ 15%, Покупки 6 200 ₽ 13%, Развлечения 3 900 ₽ 8%, Здоровье 2 100 ₽ 4%, Другое 820 ₽ 1%).
4. Таблица трат: колонки Дата · Кто · Категория · Сумма · Комментарий · действия.
   - Дата, Сумма — сортируемые (иконка-стрелка в заголовке, сейчас сортировка по дате ↓).
   - Кто — аватар-кружок с инициалом + имя.
   - Категория — Badge с цветом и иконкой категории.
   - Сумма — выровнена вправо, табличные цифры.
   - Действия — иконки «редактировать» и «удалить» (или меню «⋯»), появляются/подсвечиваются при наведении на строку.
   - 10 строк реалистичных данных (кофе 350 ₽, такси 1 200 ₽, продукты в «Пятёрочке» 3 480 ₽, аптека 890 ₽, кино 1 100 ₽, коммуналка 6 000 ₽, кроссовки 7 990 ₽ и т. п.), разные члены семьи и даты октября 2026.
5. Пагинация под таблицей: «Показано 1–10 из 37» и страницы.

Важно: итоги и диаграмма относятся ко всем тратам по фильтру, а не к текущей странице — это должно читаться из интерфейса.
```

## Промт 2 — Диалог создания и редактирования

```
Спроектируй Dialog «Новая трата» и его вариант «Редактирование траты» поверх затемнённого главного экрана.

Поля:
- Член семьи — Select (обязательно);
- Сумма, ₽ — Input с суффиксом «₽», крупный шрифт, допускает копейки (обязательно, > 0);
- Категория — сетка из 7 выбираемых «плиток» с иконкой и цветом категории (или Select — предложи, что удобнее, и покажи выбранный вариант);
- Дата — Popover с календарём, по умолчанию «Сегодня»;
- Комментарий — Textarea, необязательно, placeholder «Например: кофе с коллегами».
Кнопки: «Отмена» (secondary) и «Сохранить» (primary).

Покажи 3 состояния:
1. Пустая форма «Новая трата».
2. Ошибки валидации: сумма пустая («Укажите сумму»), категория не выбрана («Выберите категорию»).
3. «Редактирование траты» с заполненными данными (Алишер, 350 ₽, Еда, 15.10.2026, «кофе») и состоянием загрузки на кнопке «Сохранить» (спиннер, кнопка заблокирована).
```

## Промт 3 — Удаление и уведомления

```
Спроектируй:
1. AlertDialog подтверждения удаления: заголовок «Удалить трату?», в тексте кратко сама трата (Такси · 1 200 ₽ · Мадина · 14.10.2026), предупреждение «Это действие нельзя отменить». Кнопки «Отмена» и деструктивная «Удалить».
2. Toast-уведомления (sonner) в правом нижнем углу: «Трата добавлена», «Изменения сохранены», «Трата удалена», ошибка «Не удалось сохранить. Попробуйте ещё раз».
```

## Промт 4 — Состояния экрана

```
Покажи главный экран в трёх состояниях:
1. Загрузка — skeleton для карточек сводки, диаграммы и 6 строк таблицы (фильтры уже доступны).
2. Пусто — по фильтру нет трат: дружелюбная иллюстрация/иконка, текст «За выбранный период трат нет», подсказка «Измените фильтры или добавьте трату», кнопки «Сбросить фильтры» и «+ Добавить трату». Сводка показывает 0 ₽, диаграмма — пустое состояние.
3. Ошибка загрузки — сообщение «Не удалось загрузить траты» и кнопка «Повторить», остальная часть интерфейса не ломается.
```

## Промт 5 — Мобильная версия

```
Адаптируй главный экран под мобильный, ширина 390px:
- Шапка: название + иконка темы; кнопка добавления — плавающая круглая «+» в правом нижнем углу.
- Фильтры сворачиваются в кнопку «Фильтры (2)» с количеством активных, по нажатию — bottom sheet со всеми фильтрами и кнопкой «Применить». Быстрые периоды — горизонтально прокручиваемые чипы над списком.
- Сводка: «Итого» крупно, под ним компактная горизонтальная полоса долей категорий (stacked bar) с легендой, раскрывающейся по нажатию.
- Таблица превращается в список карточек: слева иконка категории, по центру комментарий и «Кто · дата», справа сумма; действия — через меню «⋯» на карточке.
- Диалог создания — во весь экран (full-screen sheet).
Покажи: главный экран, открытый bottom sheet фильтров и форму создания.
```
