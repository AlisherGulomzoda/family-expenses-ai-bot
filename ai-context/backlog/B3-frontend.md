# B3. Архитектура и технологии фронтенда

**Статус:** 🟡 черновик, ждёт одобрения
**Основа:** B1 (FR-3), B2 (REST API §4, OpenAPI).

---

## 1. Что строим

Одностраничная веб-панель главы семьи: таблица трат всех членов семьи + фильтры + создание/редактирование/удаление. Без авторизации. Адаптивная — удобно и с телефона.

## 2. Стек

| Задача | Выбор | Почему |
|---|---|---|
| Сборка | **Vite** + React + **TypeScript (strict)** | Стандарт, быстрый dev-сервер |
| UI-кит | **Mantine** (+ `@mantine/dates`, `@mantine/notifications`, `@mantine/modals`) | Готовые таблица, формы, выбор диапазона дат, русская локаль; быстро получаем аккуратный UI без своей вёрстки |
| Серверное состояние | **TanStack Query** | Кэш, загрузка/ошибки, инвалидация после мутаций |
| API-клиент | **openapi-typescript** + **openapi-fetch** | Типы генерируются из `backend/api/openapi.yaml` → фронт и бэк не расходятся |
| Формы | Mantine `useForm` | Валидация без лишних библиотек |
| Даты | `dayjs` с локалью `ru` | Используется Mantine |
| Тесты | **Vitest** + React Testing Library (+ MSW для мока API) | Несколько ключевых тестов: форма, фильтры |
| Качество | ESLint + Prettier, `tsc --noEmit` | |

Роутер не нужен (одна страница). Фильтры синхронизируются с **URL query** (`?user_id=…&from=…&to=…&category=…`) — ссылку с фильтром можно сохранить/отправить, состояние переживает перезагрузку.

## 4. Экран

```
┌─────────────────────────────────────────────────────────────┐
│ Семейные расходы                          [+ Добавить трату] │
├─────────────────────────────────────────────────────────────┤
│ [Член семьи ▾] [Период: 01.10 – 31.10 ▾] [Категория ▾] [Сброс]│
│  Быстрые периоды: Сегодня · Неделя · Этот месяц · Прошлый     │
├─────────────────────────────────────────────────────────────┤
│ Итого: 24 350 ₽ · 18 трат                                    │
├──────────┬──────────┬────────────┬─────────┬─────────┬──────┤
│ Дата     │ Кто      │ Категория  │ Сумма   │ Коммент.│      │
│ 15.10    │ Алишер   │ [Еда]      │ 350 ₽   │ кофе    │ ✎ 🗑 │
│ …        │          │            │         │         │      │
├─────────────────────────────────────────────────────────────┤
│                     ‹ 1 2 3 ›                                │
└─────────────────────────────────────────────────────────────┘
```

- **Форма (модалка)**: член семьи (select из `/api/users`), сумма в рублях (до 2 знаков), категория, дата (по умолчанию сегодня), комментарий. Валидация на клиенте + отображение ошибок полей с бэкенда (422).
- **Удаление**: диалог подтверждения (в отличие от бота, в вебе это стандартный и дешёвый шаг).
- **Состояния**: загрузка (skeleton), пусто («Трат за период нет»), ошибка (сообщение + «Повторить»), уведомления об успехе/ошибке мутаций.
- **Мобильная версия**: таблица превращается в карточки на узких экранах.
- **Итог по фильтру** приходит с бэкенда (сумма считает SQL), а не суммируется на клиенте по странице.

## 5. Интеграция с бэкендом

- Все запросы — относительные `/api/...`: в проде их проксирует nginx, в dev — Vite proxy. Нет CORS и env-переменных с URL.
- `npm run gen:api` генерирует `schema.d.ts` из `../backend/api/openapi.yaml`; сгенерированный файл коммитится (сборка в Docker не зависит от бэкенда).
- Деньги: в API `amount` в рублях (число), форматирование на клиенте через `Intl.NumberFormat('ru-RU', {style:'currency', currency:'RUB'})`.

## 6. Docker

Multi-stage: `node:lts-alpine` (npm ci, build) → `nginx:alpine` (dist + `nginx.conf`). Сервис `web` в compose, порт 8080 наружу — единственная точка входа для пользователя.

## 7. Nice-to-have (только если останется время)

- Диаграмма расходов по категориям за выбранный период (`@mantine/charts`).
- Сортировка по колонкам.
- Тёмная тема (в Mantine — почти бесплатно).
