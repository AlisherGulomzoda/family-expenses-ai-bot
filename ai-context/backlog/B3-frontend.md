## 1. Что строим

Одностраничная веб-панель главы семьи: фильтры, итог и диаграмма по категориям, таблица трат всех членов семьи с сортировкой, создание/редактирование/удаление. Без авторизации. Адаптивная (на телефоне — карточки). Светлая и тёмная тема.

## 2. Стек

| Задача | Выбор | Почему |
|---|---|---|
| Сборка | **Vite** + React + **TypeScript (strict)** | Стандарт, быстрый dev-сервер |
| Стили | **Tailwind CSS v4** (`@theme inline`, `tw-animate-css`) | Пользователь хорошо знает; тема из дизайна копируется в `globals.css` 1:1 |
| Компоненты | **shadcn/ui** (Radix UI под капотом), 28 компонентов — список в `design/design-spec.md` §4 | Компоненты копируются в репо и стилизуются Tailwind; доступность из коробки |
| Иконки | **lucide-react** | Иконки категорий и действий по дизайну |
| Шрифт | **Onest** 400/500/600/700 (woff2 в `public/fonts`, из дизайн-системы) | Хорошая кириллица, табличные цифры |
| Таблица | **TanStack Table** (через shadcn Data Table) | Сортировка колонок, управляемое состояние |
| Даты | shadcn **Calendar** (react-day-picker) + `date-fns` с локалью `ru` | Выбор диапазона дат |
| Диаграмма | shadcn **Charts** (Recharts) | Расходы по категориям |
| Формы | **react-hook-form** + **zod** (shadcn Form) | Стандарт для shadcn, типобезопасная валидация |
| Уведомления | **sonner** (shadcn) | |
| Тёмная тема | **next-themes** (`attribute="class"`), класс `.dark` на `<html>` | По дизайну; сохраняет выбор, учитывает системную тему |
| Серверное состояние | **TanStack Query** | Кэш, загрузка/ошибки, инвалидация после мутаций |
| API-клиент | **openapi-typescript** + **openapi-fetch** | Типы из `backend/api/openapi.yaml` — фронт и бэк не расходятся |
| Тесты | **Vitest** + React Testing Library (+ MSW) | Форма, фильтры ↔ URL, форматирование денег |
| Качество | ESLint + Prettier, `tsc --noEmit` | |

Роутер не нужен (одна страница). Фильтры и сортировка синхронизируются с **URL query** (`?user_id=…&from=…&to=…&category=…&sort=…&order=…&page=…`).

## 4. Экран (каркас, финальный вид — по дизайну §9)

```
┌──────────────────────────────────────────────────────────────┐
│ Семейные расходы                    [☀/☾]  [+ Добавить трату] │
├──────────────────────────────────────────────────────────────┤
│ [Член семьи ▾] [Период ▾] [Категория ▾] [Сбросить]           │
│ Быстро: Сегодня · Неделя · Этот месяц · Прошлый месяц         │
├────────────────────────┬─────────────────────────────────────┤
│ Итого: 24 350 ₽        │  Диаграмма по категориям            │
│ 18 трат                │  ███ Еда 9 800 ₽ ...                │
├────────────────────────┴─────────────────────────────────────┤
│ Дата ↓ │ Кто    │ Категория │ Сумма ↕ │ Комментарий │ ⋯       │
│ 15.10  │ Алишер │ [Еда]     │ 350 ₽   │ кофе        │ ✎ 🗑    │
├──────────────────────────────────────────────────────────────┤
│                         ‹ 1 2 3 ›                            │
└──────────────────────────────────────────────────────────────┘
```

- **Форма (диалог)**: член семьи, сумма в рублях (до 2 знаков), категория, дата (по умолчанию сегодня), комментарий. zod-валидация + ошибки полей с бэкенда (422).
- **Удаление**: AlertDialog с подтверждением.
- **Состояния**: skeleton при загрузке, пустое состояние, ошибка с «Повторить», toast об успехе/ошибке.
- **Итог и диаграмма** считаются на бэкенде (`/api/expenses/summary`) по тем же фильтрам — не по текущей странице.
- **Сортировка** — серверная (из-за пагинации): по дате, сумме, дате создания.

## 5. Интеграция с бэкендом

- Все запросы относительные `/api/...`: в проде — nginx, в dev — Vite proxy. Без CORS.
- `npm run gen:api` генерирует `schema.d.ts`; сгенерированный файл коммитится.
- Деньги в API — рубли (число), форматирование `Intl.NumberFormat('ru-RU', {style:'currency', currency:'RUB'})`.

## 6. Docker

Multi-stage: `node:lts-alpine` (npm ci, build) → `nginx:alpine`. Сервис `web`, порт 8080 наружу.

### 9.2 Что дизайн уточнил (принимаем)
- Tailwind v4, next-themes, шрифт Onest, иконки lucide; категории закреплены за `chart-1…7` (коды совпадают с бэкендом, `entertainment` — не `fun`).
- Главная граница адаптива — `md` (768px): ниже — карточки, фильтры в Drawer, форма во весь экран.
- На телефоне вместо пагинации — «Показать ещё» (догрузка по 10, тот же `offset`).
- 10 трат на страницу → фронт передаёт `limit=10`.
- «Средняя трата» = `total / count` из `/api/expenses/summary` (считаем на клиенте, отдельного поля не нужно).
- «По категориям»: на десктопе — строки с Progress, на телефоне — stacked BarChart + Collapsible-легенда.
- Ширина контента — 1280px (а не 1120px из дизайн-системы — иначе фильтры не помещаются).
- Сортировка в UI — только «Дата» и «Сумма» (API поддерживает больше — ок).

### 9.3 Расхождения с решениями и как их закрываем
