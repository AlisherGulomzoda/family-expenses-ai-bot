# CLAUDE.md — точка входа для ИИ-ассистента

Проект: тестовое задание «ИИ-бот учёта семейных расходов» (Telegram-бот с LLM-агентом + веб-панель, Go + React/TS, docker compose).

## Как продолжить работу (с любого устройства)

1. Прочитай `ai-context/00-status.md` — текущий этап и следующий шаг.
2. Прочитай `ai-context/03-workflow.md` — правила работы с пользователем (обязательно).
3. По необходимости: `01-task.md` (суть ТЗ), `02-decisions.md` (принятые решения), `backlog/`, `tickets/`.
4. После каждого значимого изменения/решения обнови `00-status.md` и связанные файлы.

## Ключевые правила (кратко)

- Язык общения — русский. Пользователь — Алишер, пишет на Go, фронт — React + TypeScript.
- Процесс: **бэклог → одобрение → декомпозиция на тикеты (бэк/фронт) → одобрение → реализация**. Не писать код до одобрения тикетов.
- Git делает пользователь сам (коммиты, ветки, пуши). Ассистент только предлагает текст коммита — см. `ai-context/commits.md`.
- Идеи «на будущее» складывать в `ai-context/future-improvements.md` — из них соберём сопроводительное письмо.
